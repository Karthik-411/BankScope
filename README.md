BankScope
A digital banking platform landing page built with React, Vite, and Tailwind CSS
🔗 Live Demo: [add your Vercel/Netlify link here]

Overview
BankScope showcases a "Prospective Customer Segmentation" concept for a digital banking product, dividing potential users into four groups — Satisfied, Underserved, Expert, and Underbanked

Features
🎨 Clean, responsive UI built with Tailwind CSS
🧩 Component-based architecture (Navbar, Herotext, Content, Leftcontent, Rightcontent, Rightcard, Arrow)
🔠 Icon integration via Remixicon
⚡ Fast dev environment powered by Vite
